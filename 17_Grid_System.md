# Objetivo

Definir el sistema de retículas que organizará todo el contenido del ecosistema La Martina.

La retícula garantiza consistencia, alineación y equilibrio visual.

---

# Filosofía

Todo debe alinearse.

Nada debe colocarse por intuición.

La retícula gobierna el diseño.

# Imágenes

Nunca ocupar el 100% del ancho salvo en banners específicos.

Mantener proporciones.

---

# Alineaciones

Todo elemento debe alinearse a la retícula.

No utilizar posiciones arbitrarias.

---

# Ritmo Vertical

Las secciones comienzan siempre alineadas.

Las imágenes siguen la misma línea base del contenido.

---

# Responsive

El contenido nunca debe romper la retícula.

Solo cambia el número de columnas.

---

# No permitido

Elementos flotando sin alineación.

Columnas diferentes dentro de la misma sección.

Gutters variables.

---

# Resultado esperado

Toda la interfaz debe transmitir precisión, estabilidad y orden visual incluso sin observar conscientemente la retícula.
