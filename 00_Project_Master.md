# Visión

Crear la experiencia digital más inspiradora para una escuela de gastronomía online de Latinoamérica.

No construiremos únicamente una página web.

Construiremos un ecosistema digital donde cada interacción transmita calidad, inspiración y confianza.

---

# Nuestra Filosofía

Toda decisión deberá responder una pregunta:

¿Esto ayuda al estudiante?

Si la respuesta es no, no pertenece al proyecto.

---

# Objetivos

Crear una identidad visual única.

Crear una experiencia de navegación memorable.

Diseñar una plataforma preparada para crecer durante muchos años.

Construir un sistema reutilizable.

Crear una marca digital reconocible.
