# Reglas UX

Nunca más de una acción principal por pantalla.

Siempre mostrar el siguiente paso.

Eliminar decisiones innecesarias.

Reducir fricción.

Mostrar progreso.

Guardar automáticamente cuando sea posible.

# Resultado Esperado

Cada flujo debe sentirse natural, rápido y predecible.

El usuario nunca debe preguntarse:

"¿Y ahora qué hago?"

Siempre debe existir un siguiente paso claramente visible.
