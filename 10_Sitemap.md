# SEO

Cada curso tendrá URL propia.

Ejemplo:

/cursos/pasteleria-profesional

Cada artículo:

/blog/como-hacer-croissant

Cada categoría:

/escuelas/panaderia

---

# Reglas

Nunca más de tres niveles de profundidad.

Todas las páginas deben estar conectadas.

No deben existir páginas huérfanas.

Toda página debe tener breadcrumbs cuando corresponda.

---

# Objetivo Final

El usuario debe llegar a cualquier curso en un máximo de tres clics.
