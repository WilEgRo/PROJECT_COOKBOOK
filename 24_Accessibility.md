Versión: 1.0

Estado: Aprobado

Última actualización:
17 Julio 2026

Dependencias:
23_Responsive_Strategy.md

---

# Objetivo

Garantizar que cualquier persona pueda utilizar La Martina independientemente de sus capacidades físicas, cognitivas o tecnológicas.

La accesibilidad no es una función adicional.

Es parte del diseño.

---

# Filosofía

Diseñar para todos.

Eliminar barreras.

Facilitar el aprendizaje.

Nunca excluir usuarios.

---

# Estándar

Cumplir WCAG 2.2 Nivel AA.

Todo el proyecto debe desarrollarse siguiendo este estándar.

---

# Contraste

Texto normal

Mínimo 4.5:1

Texto grande

Mínimo 3:1

Botones

Contraste AA

Nunca utilizar gris claro sobre blanco.

---

# Tipografía

Tamaño mínimo

16 px

Interlineado

1.5

Espaciado entre párrafos

1.8

Nunca justificar texto.

---

# Navegación

Todo debe funcionar con teclado.

Orden lógico de TAB.

Focus visible.

Escape debe cerrar modales.

Enter activa botones.

Espacio activa controles.

---

# Mouse

Nunca depender únicamente del hover.

Toda acción disponible con teclado.

---

# Screen Readers

Todas las imágenes importantes tendrán ALT.

Los iconos decorativos serán aria-hidden.

Todos los botones tendrán nombre accesible.

Los formularios tendrán labels.

---

# Formularios

Label visible.

Errores claros.

Ayuda contextual.

Validación inmediata.

Nunca usar solo color para indicar error.

---

# Botones

Área mínima

48x48 px

Separación suficiente.

Estados claros.

---

# Animaciones

Respetar prefers-reduced-motion.

Reducir parallax.

Eliminar movimientos innecesarios.

---

# Multimedia

Videos con subtítulos.

Transcripciones.

Controles accesibles.

Sin reproducción automática con sonido.

---

# Imágenes

Texto alternativo descriptivo.

No repetir el texto visible.

Describir únicamente información relevante.

---

# Colores

Nunca comunicar información únicamente mediante color.

Combinar:

Color

Texto

Ícono

---

# Dashboard

Navegación consistente.

Atajos de teclado.

Estados anunciados.

---

# Errores

Explicar el problema.

Indicar cómo solucionarlo.

No mostrar códigos técnicos al usuario.

---

# Responsive

Todos los elementos táctiles:

48x48 px mínimo.

Separación suficiente.

---

# SEO

La accesibilidad mejora el SEO.

Todo HTML debe ser semántico.

---

# Checklist

✓ Contraste

✓ Focus

# Resultado esperado

La Martina debe poder ser utilizada cómodamente por la mayor cantidad posible de personas sin perder elegancia ni calidad visual.
