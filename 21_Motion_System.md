# Objetivo

Definir el lenguaje de movimiento de La Martina.

Las animaciones deben sentirse naturales, elegantes y cinematográficas.

Nunca deben existir únicamente para llamar la atención.

Cada movimiento debe tener una razón.

# Scroll

La página debe sentirse viva.

Mientras el usuario hace scroll:

El contenido aparece progresivamente.

Las imágenes tienen un ligero efecto parallax.

El fondo cambia muy sutilmente.

Nunca provocar mareo.
