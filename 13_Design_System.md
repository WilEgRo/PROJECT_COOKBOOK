# Objetivo

Crear un lenguaje visual unificado para todo el ecosistema de La Martina.

Todo debe parecer diseñado por el mismo estudio.

La experiencia debe ser consistente desde la Home hasta el Dashboard del alumno.

---

# Filosofía

Elegancia.

Calidez.

Artesanía.

Orden.

Minimalismo.

Precisión.

Premium.

---

# Valores del diseño

Menos elementos.

Más intención.

Menos decoración.

Más significado.

Menos ruido.

Más contenido.

# Principios

Consistencia

Jerarquía

Respiración

# Identidad Visual

Inspiración

Panadería artesanal.

Alta pastelería.

Editorial moderna.

Cafetería de especialidad.

Lujo silencioso.

---

# Sensaciones

El usuario debe pensar:

"Aquí sí aprenderé."

"Qué bonito."

"Se siente profesional."

"No parece un curso barato."

---

# Lenguaje Visual

Mucho espacio negativo.

Elementos alineados.

Fotografía protagonista.

Tipografía elegante.

Animaciones suaves.

Sombras discretas.

Bordes limpios.

Nada estridente.

Radio

Espaciado

Tipografía

Animaciones

Estados

Colores

---

# Botones

Solo dos acciones principales por pantalla.

Primario

Secundario

Evitar más de tres botones visibles simultáneamente.

---

# Tarjetas

Radio consistente.

Imagen superior.

Información jerarquizada.

Botón claro.

Hover elegante.

---

# Formularios

Campos amplios.

Etiquetas visibles.

Errores claros.

Validación inmediata.

Accesibles.

---

# Fotografías

Reales.

Alta resolución.

Luz natural.

Ingredientes frescos.

Personas auténticas.

Nunca imágenes falsas o excesivamente posadas.

---

# Iconografía

Simple.

Consistente.

Trazo uniforme.

Sin estilos mezclados.

---

# Ilustraciones

Uso mínimo.

Solo cuando aporten comprensión.

Nunca sustituir fotografías reales de productos.

---

# Motion

Todo movimiento debe comunicar.

Nunca decorar.

Duración corta.

Curvas suaves.

Sin efectos exagerados.

---

# Responsive

Desktop primero.

Tablet optimizada.

Mobile cuidadosamente adaptado.

No ocultar contenido importante.

---

# Accesibilidad

Contraste suficiente.

Navegación por teclado.

Estados de foco.

Texto escalable.

Lectores de pantalla.

---

# Consistencia

Cada página debe sentirse parte del mismo ecosistema.

No mezclar estilos.

No mezclar componentes.

No cambiar reglas según la sección.

---

# Escalabilidad

El sistema debe permitir crear:

Landing Pages

Cursos

Blog

Dashboard

Marketplace

Comunidad

App móvil

Sin necesidad de rediseñar la identidad visual.

---

# Regla de Oro

Antes de crear un nuevo componente, verificar si ya existe uno que pueda reutilizarse.

La consistencia siempre tiene prioridad sobre la creatividad aislada.

---

# Checklist

✓ Coherencia visual

✓ Componentes reutilizables

✓ Escalable

✓ Accesible

✓ Responsive

✓ Preparado para desarrollo

✓ Preparado para IA

---

# Resultado esperado

Cualquier diseñador o desarrollador que se incorpore al proyecto debe ser capaz de crear nuevas pantallas respetando este documento sin romper la identidad de La Martina.
