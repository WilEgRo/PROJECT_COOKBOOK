# Objetivo

Definir la jerarquía tipográfica del ecosistema La Martina.

La tipografía debe transmitir confianza, elegancia y claridad.

---

# Filosofía

Leer debe sentirse fácil.

Nunca cansado.

Nunca comprimido.

Mucho aire.

Mucho espacio.

---

# Personalidad

Editorial.

Elegante.

Contemporánea.

Humana.

Premium.

---

# Combinación recomendada

Familia Serif

Para títulos.

Familia Sans Serif

Para interfaz.

Nunca utilizar más de dos familias tipográficas.

---

# Alineación

Texto largo:

Izquierda.

Nunca justificar.

Títulos:

Izquierda.

# Longitud

70 caracteres por línea.

# Uso de Mayúsculas

Solo:

Botones pequeños.

Etiquetas.

Nunca escribir párrafos completos en mayúsculas.

---

# Uso de Cursivas

Solo para destacar frases.

Nunca para párrafos completos.

Desktop

# Accesibilidad

Interlineado amplio.

Contraste suficiente.

Tamaño mínimo legible.

Nunca usar texto inferior a 14 px para contenido principal.

---

# Principios

Respirar.

Leer fácil.

Crear ritmo.

Guiar la mirada.

Transmitir lujo.

---

# Resultado esperado

La tipografía debe sentirse como una revista gastronómica de alta calidad y permitir una lectura cómoda en cualquier dispositivo.
