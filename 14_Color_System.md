# Objetivo

Definir el sistema cromático oficial de La Martina para mantener una identidad consistente en todas las plataformas.

El color debe transmitir elegancia, confianza, artesanía y calidez.

Nunca debe sentirse tecnológico ni corporativo.

# Reglas

El fondo debe ocupar aproximadamente el 70% de la composición.

El color primario no debe superar el 15%.

Los acentos no deben superar el 5%.

---

# Contraste

Todo texto debe cumplir WCAG AA.

Nunca utilizar texto gris claro sobre fondo claro.
