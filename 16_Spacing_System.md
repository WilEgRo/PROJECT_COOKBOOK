# Objetivo

Definir un sistema de espaciado consistente que proporcione orden, elegancia y ritmo visual en todas las interfaces de La Martina.

El espacio en blanco es un elemento de diseño, no un espacio vacío.

---

# Filosofía

Respirar.

Ordenar.

Guiar.

Simplificar.

Cada espacio tiene un propósito.

---

# Unidad Base

Nunca utilizar medidas aleatorias.

# Regla de Respiración

Ningún componente debe sentirse comprimido.

Si existe duda entre dos espacios, elegir el mayor.

---

# Espacio Negativo

Debe representar aproximadamente el 40% de la composición visual.

El lujo se percibe mediante el espacio.

---

# Responsive

Reducir únicamente los márgenes exteriores.

Nunca reducir el aire interno de los componentes.

---

# No permitido

Espaciados diferentes para elementos similares.

Padding arbitrario.

Componentes pegados entre sí.

---

# Resultado esperado

La interfaz debe sentirse amplia, elegante y ordenada desde cualquier resolución.
